# Addressable LED Dome for Electromagnetic Field

![Video of the dome with various LED animations](media/emfdome2026-720.mp4 "Video of the dome with various LED animations")

Every two years Dogsbody Technology attends the [Electromagnetic Field festival](https://www.emfcamp.org/), which can only be described as Glastonbury for geeks, and WE LOVE IT!

At each event we try to build something bigger and better.

In 2024 [we built a huge geodesic dome](https://www.dogsbody.com/blog/electromagnetic-field-2024-the-best-yet/), and in 2026 we are covering the entire thing with 150 metres of 5,000 individually addressable RGB LEDs for interactive lighting, patterns, games and general tinkering!

This repository contains the design notes, wiring plans, controller configuration, layout files and supporting documentation for the project.

## Quick facts

- 6 metre diameter geodesic dome
- 165 wooden struts
- 5,000 WS2815 pixels
- Five 30 metre strings
- Five QuinLED Dig-Uno controllers
- Five 12 V, 100 W power supplies
- WLED and Python software
