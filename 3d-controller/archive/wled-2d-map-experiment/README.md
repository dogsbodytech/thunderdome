# Archived WLED 2D-map experiment

This is an SVG-derived, uncalibrated first-pass 300×300 mapping experiment. It is not authoritative physical geometry. WLED `ledmap.json` is not used by the intended Python 3D renderer. The data, upload helpers, clock tests, and prompts remain only for historical comparison and mapping diagnostics.

Run its old tests with `PYTHONPATH=controller:archive/wled-2d-map-experiment/code python3 -m unittest discover -s archive/wled-2d-map-experiment/tests -v`.
