# Quickstart

This page is retained as a compatibility link for older bookmarks. The operational journey is now split so that simulator use is safe and physical output is explicit.

- [Start here](START-HERE.md) if you remember almost nothing.
- [Cold start](runbooks/cold-start.md) for the complete path.
- [Software and simulator](runbooks/software-and-simulator.md) for a hardware-free moving browser view.
- [Physical dome startup](runbooks/physical-dome-startup.md) after the software checkpoint.
- [First light and DDP](runbooks/first-light-and-ddp.md) for layered physical commissioning.
- [Normal operation](runbooks/normal-operation.md) and [shutdown](runbooks/shutdown.md) for event use.

Normal brightness is `255`. Simulator commands use explicit `--output simulator`; physical effect commands use explicit `--output ddp` or `--output both`. See [WLED and DDP](reference/wled-and-ddp.md) for the boundary.
