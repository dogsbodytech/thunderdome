# Route capture

Write manual routes as ordered hubs, for example `H032 > H019 > ... > H061`. Each adjacent pair must be a real spar. Hubs may repeat. Spars may not be shared by different strings. Every string ends at H061. `geometry/reference_string_route.md` contains the five manually captured authoritative string routes. Rotational symmetry is historical capture context only; it is not used to infer the active routes.
