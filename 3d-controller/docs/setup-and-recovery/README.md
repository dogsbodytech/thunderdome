# Setup and recovery

## Common cases

Use these documents when a component has been rebuilt, reset, replaced, or is no longer known-good. They prepare one component; the numbered runbooks prove and operate the complete system.

| Situation | Read this | Rejoin the main sequence |
| --- | --- | --- |
| Controller computer lost or rebuilt | [Controller Host](controller-host.md) | [01 — Software and simulator](../runbooks/01-software-and-simulator.md), then 02 → 03 → 04 → 05 |
| WLED controller reset or replaced | [WLED Controller](wled-controller.md) | [02 — Physical dome startup](../runbooks/02-physical-dome-startup.md), then 03 → 04 → 05 |

Do not begin routine event operation from this directory. For the complete order, use the [runbook index](../runbooks/README.md). Do not copy passwords, Wi-Fi credentials, tokens, or whole WLED exports into this directory.
