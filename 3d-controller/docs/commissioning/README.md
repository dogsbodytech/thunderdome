# Commissioning

Commissioning changes the local controller host or a WLED device. It is separate from routine operation.

| Situation | Procedure |
| --- | --- |
| WLED device reset/replaced | [WLED controller commissioning](wled-controller.md) |
| Controller computer rebuilt | [Rebuild controller host](rebuild-controller-host.md) |
| First physical light after commissioning | [First light and DDP](../runbooks/first-light-and-ddp.md) |

Do not copy passwords, Wi-Fi credentials, tokens, or whole WLED exports into this directory. The public repository links below are evidence/reference, not a guarantee that the current device has that state.
